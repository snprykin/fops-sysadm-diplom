# Курсовой работа на профессии "DevOps-инженера с нуля"

## Описание
Отказоустойчивая инфраструктура в Yandex Cloud с мониторингом, сбором логов и резервным копированием.

## Архитектура
- 2 web-сервера (nginx) в разных зонах
- Application Load Balancer
- Zabbix для мониторинга
- ELK для сбора логов
- Bastion host для безопасного доступа
- Ежедневные снапшоты с недельным сроком хранения

## Развертывание
1. Настройте Yandex Cloud и создайте сервисный аккаунт
2. Настройте `terraform/terraform.tfvars`
3. Выполните `terraform apply`
4. Запустите Ansible плейбуки
